# Тук-тук

**Нагадувалка, яка тукає знову і знову, поки ти не зробиш справу.**

Звичайні нагадування спрацьовують один раз, їх легко змахнути й забути. Тук-тук повторює нагадування із заданим інтервалом, поки не натиснеш «Готово».

## Можливості

- Повторювані нагадування з інтервалом від 15 хвилин до 3 годин, лише у вибрані години
- Кнопки «Готово» і «Через 15 хв» прямо в сповіщенні
- Наростання наполегливості: «Тук-тук!» → «Знову тук-тук» → «Я не відстану»
- Дедлайни з датою і часом
- Події в Google Календар з редагуванням і синхронізацією
- Зведення всіх справ кілька разів на день
- Історія виконаного і підсумок «Виконано за 2 год, після 3 нагадувань»
- Дані лише на пристрої: без акаунтів, реклами й аналітики

## Технології

React Native · Expo SDK 57 · SQLite · expo-notifications · expo-calendar · EAS Build
