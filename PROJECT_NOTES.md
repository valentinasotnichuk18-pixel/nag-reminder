## 1. Що це

Android-нагадувалка, яка повторює нагадування із заданим інтервалом, поки справу не позначать "Готово". Створена на основі моєї автоматизації в n8n і Telegram.

**Головний принцип:** застосунок має тукати, поки не зробиш, тобто спонукати до дії.

## 2. Як працювати

### Запуск для розробки
1. `cd C:\Users\Asus\nag-reminder`
2. `npx expo start`
3. На телефоні відкрити збірку для розробки. Після змін у коді натиснути **r** у терміналі

### Збірки (EAS)
| Профіль | Команда | Для чого |
|---|---|---|
| development | `eas build -p android --profile development` | Розробка, потрібен термінал |
| preview | `eas build -p android --profile preview` | APK для щоденного користування, без терміналу |
| production | `eas build -p android --profile production` | AAB для Google Play |

Нова збірка потрібна лише тоді, коли додається нова бібліотека або змінюється app.json. Зміни в App.js підтягуються через **r**.

Усі збірки мають однаковий пакет, тому нова збірка замінює попередню. Дані при цьому зберігаються.

На питання "Install and run on an emulator?" відповідати **n**.

### Збереження в GitHub
```
cd C:\Users\Asus\nag-reminder
git add .
git commit -m "Опис змін"
git push
```

### Як працюємо з Claude
1. Одна задача за раз
2. Claude змінює файли напряму в папці (чат має бути пов'язаний з ноутбуком через застосунок Claude)
3. Після кожної зміни Claude дає чекліст у форматі "що + де + після якої дії"
4. Я перевіряю і пишу "пас" або надсилаю баг: скріншот, кроки, Current і Expected
5. Перед зміною App.js Claude спершу читає актуальний файл з ноутбука

## 3. Технології

React Native, Expo SDK 57, expo-sqlite, expo-notifications, expo-calendar (новий об'єктний API), @react-native-community/datetimepicker, react-native-svg, шрифт Nunito, EAS Build.

Весь код в одному файлі **App.js**.

### База даних (SQLite, лише на телефоні)
| Таблиця | Що зберігає |
|---|---|
| tasks | Справи: назва, статус active або done, дата створення, дата виконання, дедлайн |
| events | Події, створені через Тук-тук: id в календарі, назва, початок, кінець, нагадування |
| settings | Налаштування: інтервал, години роботи, зведення, onboarding_done |

## 5. Стан

### Готово
Справи з дедлайном, нагадування з інтервалом, кнопки "Готово" і "Через 15 хв" у сповіщенні, "Повернути", підсумок "Виконано за...", зведення, події з редагуванням і синхронізацією, історія, захист від ліміту сповіщень, довідка при першому запуску, налаштування, Privacy Policy, значок і зелений дизайн, групування списку, preview APK.

### Наступні кроки до MVP
1. Сховати блок "Для тестування" у фінальній збірці
2. Опис, скріншоти, анкета Data Safety для Google Play
3. Production-збірка (AAB)
4. Акаунт розробника, закрите тестування (12+ тестувальників, 14 днів), публікація

### Відкриті питання
- Додати в тест-план і довідку ризик режиму екстремальної економії батареї
- Перевірити статуси TC-54..58 (довідка, Privacy Policy)
